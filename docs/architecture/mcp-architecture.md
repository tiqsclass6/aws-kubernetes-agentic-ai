# **MCP Architecture**

Only the Remediation Agent holds an MCP client certificate. The Observer Agent never calls MCP. Slack and Jira are optional Reporting Agent integrations, not MCP tools.

```text
                Remediation Agent (ai-agents)
                        |
                        | client certificate, port 8443
                        | (NetworkPolicy: only remediation-agent may connect)
                        v
                +-----------------------------------+
                | mcp-gateway namespace             |
                |                                   |
                | ServiceAccount: mcp-gateway-sa    |
                | automountServiceAccountToken:     |
                |   false                           |
                |                                   |
                | NGINX mTLS Gateway                |
                | - ssl_verify_client on            |
                | - terminates TLS                  |
                | - forwards every verified request |
                |   with X-Client-Verify and        |
                |   X-Client-DN headers             |
                +-----------------+-----------------+
                                  |
                                  | port 9000
                                  | (NetworkPolicy: only mcp-gateway may connect)
                                  v
                +-----------------------------------+
                | mcp namespace                     |
                |                                   |
                | MCP Server                        |
                | - trusts the gateway's client-    |
                |   certificate headers             |
                | - tools: get_pods, get_logs,      |
                |   restart_deployment              |
                | - re-validates approval source,   |
                |   namespace and deployment        |
                |   allowlists                      |
                | - publishes audit events to       |
                |   guardian-audit and              |
                |   raw-security-events             |
                | - app01-scoped RBAC only          |
                +-----------------+-----------------+
                                  |
                                  v
                +-----------------------------------+
                | Controlled tool target            |
                |                                   |
                | Kubernetes API in app01           |
                | (allowlisted deployment)          |
                +-----------------------------------+
```

The gateway authenticates the caller; the MCP Server authorizes the tool call. Because the server trusts the `X-Client-*` headers set by nginx, the NetworkPolicy that limits port 9000 to the gateway is part of the trust boundary.

Certificates are generated by `scripts/07-generate-mcp-mtls.sh` and applied as Kubernetes Secrets. Rotate by re-running that script, then restart `mcp-gateway`, `mcp-server`, and `remediation-agent`.
